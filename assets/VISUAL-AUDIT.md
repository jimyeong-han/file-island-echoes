# 화면·에셋 점검 기록 · 2026-09-09

작업 시작 시 Git 작업 트리는 깨끗했습니다. 적용 대상 AGENTS.md는 없었고, 기존 TypeScript + Vite 구조를 유지했습니다. 전투 규칙, 콘텐츠 수치, 저장 스키마, 진행 흐름 파일은 변경하지 않았습니다.

## 변경 전

- public/art/에 SVG 12개: 캐릭터 11개는 24×24 격자 표현을 150×150 SVG로 출력한 임시 그림, 지역 그림은 1100×650 SVG였습니다. 파일당 약 8–20 KiB였습니다.
- 브라우저 첫 전투 실측: 상태표 48px, 아구몬 170px, 적 145px. 같은 작은 격자 그림을 확대해 쓰고 있었습니다.
- 타이틀과 모든 이야기에서 같은 도형 섬 그림을 공유했고, 지원 인물 초상화가 없었습니다.
- 공격/방어/이벤트/육성 아이콘과 모닥불이 문자 기호였습니다. 일반 적 여러 종의 실루엣이 유사했습니다.
- 타이틀, 지도, 전투, 보상, 이벤트, 휴식, 일반 진화, 보스, 결과, 도감, 안내/설정/정보/덱 및 경고의 코드를 점검했습니다. 기존 공개 빌드를 새 탐험부터 메탈그레이몬·데블몬 승리까지 직접 조작했습니다.

| 화면 | 새 에셋과 표현 |
| --- | --- |

| 지도 | 숲/공장/산 배경, SVG 노드, 빛의 연결선, 진행 상태와 파트너 링 |
| 전투 | 지역별 배경, 파트너 4형태 + 적 7종, 선택 대상 표시, 행동 예고 SVG, 분리된 바닥 그림자 |
| 이벤트 | 구현된 이야기 9개에 7개의 해당 인물 쌍 초상화 연결 (태일 포함), 지역 배경 |

| 진화 미리보기/연출 | 해당 형태 이미지, 위험 경고, 진화 전후 교체, 링·빛·입자 |
| 결과 | 현재 파트너, 승리/패배 표식, 기억을 되찾은 숲 또는 산 배경 |
| 도감 | 새 이미지 전체, 미발견 실루엣, 일관된 프레임 |
| 설정/정보/안내/덱 | 게임 대화창 프레임, SVG 아이콘, 키보드 포커스, 44px 버튼 |

## 적용 후 조정

- 모바일 390px, 최소 320px, 데스크톱 1280px에서 검사했습니다. 320px에서 body 최소 너비 및 고정 배경의 100vw 때문에 생기던 가로 넘침을 제거했습니다.
- 원형 그림자를 이미지에서 분리했고 object-fit: contain으로 뿔·발·날개를 담습니다. 알파 외곽에는 약 2.5% 안전 여백을 둡니다.
- 초상화의 장식선을 프레임 왼쪽으로 고정하고, 타이틀 홀로그램 경계를 부드럽게 조정했습니다.
- 어두운 데블몬은 CSS 명도와 외곽 빛, 배경 역광을 보강했습니다.
- 전투 연출은 카드 종류와 실제 선택 대상에 맞췄습니다. 규칙 계산은 기존 엔진을 그대로 호출합니다.
- 자세한 실제 플레이 검증과 한계는 [VALIDATION.md](../VALIDATION.md), 파일별 사양은 [ASSETS.md](../ASSETS.md)를 참조하세요.
