# v0.5 — 배경음악과 효과음

- 상태: 완료
- 선행 버전: v0.4
- 제품 버전: `0.5.0`
- 작성일: 2026-09-10
- 구현 기준: `53404ff`, `ace8c7e`

## 목표

화면·지역·전투 상황에 맞는 독창적인 배경음악, 징글과 효과음을 만들고 브라우저 자동재생 정책을 지키는 중앙 오디오 시스템에 연결한다.

## 구현 기록

- `53404ff`: 직접 제작한 12곡, 징글 17개, 효과음 41개와 중앙 오디오 믹서 구현
- `ace8c7e`: GitHub Pages의 MP3 MIME 검사 수정과 공개 배포 오디오 검증 기록
- 상세 제작·용량·브라우저 검증: 루트 `AUDIO.md`

## 다른 세션에 전달할 프롬프트

```text
File Island Echoes v0.4에 v0.5 오디오를 실제로 제작하고 적용해줘. 공식 애니메이션과 게임의 음악, 주제가, 진화 음악, 음성 및 효과음을 추출하거나 식별 가능하게 모방하지 않는다. 사용할 수 있는 오디오 생성 도구가 없으면 로컬 신시사이저와 오디오 처리 도구로 독창적인 음악과 효과음을 제작한다. 테스트용 비프음만 넣은 상태를 완성으로 처리하지 않는다.

타이틀, 캐릭터 선택/도감, 지도, 숲, 공장, 무한산, 일반 전투, 강적, 공통 보스, 에테몬, 묘티스몬과 스토리 장면의 반복 음악을 만든다. 문장 준비, 8명 각각의 문장 발동, 일반/강제 진화, 승리, 패배, 카드 획득, 챕터 완료와 도감 해금에는 짧은 징글을 사용한다.

버튼·지도·카드 드로우/선택/사용/버림/셔플, 공격 속성, 방어, 회복, 상태 적용/정화, 적 예고/등장/피격/정화/격퇴, 문장 충전, 진화 에너지, 데이터 집중, 강제 진화 경고, 오염과 부담에 효과음을 연결한다. 반복 효과에는 소수 변형이나 미세한 피치 차이를 사용하고 동시 재생을 제한한다.

하나의 AudioContext와 Master/Music/SFX 버스를 가진 중앙 AudioManager를 구현한다. 전체·음악·효과음 음량, 음소거, 크로스페이드, 징글 덕킹, 동일 음악 위치 재사용, 지연 로딩, 포맷 대체, 로드 실패 복구, 탭 백그라운드 suspend/resume을 지원한다. 첫 사용자 입력 전에는 AudioContext와 오디오 요청을 시작하지 않는다. 설정과 음량은 기존 저장에 기본값을 채우며 localStorage에 유지한다.

오디오는 중앙 매니페스트에서 ID, 경로, 종류, 기본 음량, 반복, 동시 제한, 변형과 페이드 시간을 관리한다. 카드와 문장 데이터는 파일 경로 대신 audioId를 참조한다. OGG와 MP3 등 브라우저 대체 형식을 제공하고 WAV 마스터는 배포하지 않는다. 첫 타이틀 오디오 전송은 약 2MB 이하, 전체는 약 15MB 이내를 목표로 한다.

압축 파일 전체를 디코딩해 길이, 피크, 앞뒤 무음과 루프 경계를 검사한다. 실제 브라우저에서 자동재생 게이트, 믹서 설정 저장, 화면별 음악, 일반/강제 진화, 승패, 8개 문장 소리, 중첩 제한, 포맷 대체, 로드 실패, 모바일 입력과 Pages 경로를 검증한다. AUDIO.md에 제작 방식, 전체 큐, 배치, 용량, 재생성 방법, 검증 결과와 청취 한계를 기록한다.

package.json과 사용자에게 표시되는 버전을 0.5.0으로 맞춘다. 모든 검증을 마친 뒤 이 문서의 상태를 완료로 갱신하고 구현 기준과 관련 문서를 기록한다.
```

## 완료 조건

- 음악 12개 안팎, 문장·진화·결과 징글과 게임 동작 효과음이 실제 화면에 연결된다.
- 자동재생 제한, 음량 저장, 지연 로드, 중첩 제한과 실패 복구가 동작한다.
- 테스트·빌드·Pages 검사와 실제 브라우저 오디오 흐름이 문서화된다.
