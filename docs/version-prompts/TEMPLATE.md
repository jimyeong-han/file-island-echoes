# v0.x — 기능명

- 상태: 초안
- 유형: 기능 버전
- 선행 버전: v0.x
- 제품 버전: `0.x.0`
- 작성일: YYYY-MM-DD

## 목표

이 버전에서 사용자가 얻게 될 결과를 한두 문장으로 적는다.

## 범위

- 포함할 기능
- 변경할 콘텐츠
- 저장 및 호환성 영향
- 성능·접근성 요구사항

## 다른 세션에 전달할 프롬프트

```text
현재 저장소의 File Island Echoes를 v0.x로 확장해줘.

먼저 저장소와 AGENTS.md, docs/version-prompts/README.md, 직전 버전 프롬프트, 현재 코드·문서·테스트·Git 상태를 확인한다. 기존 사용자 변경사항을 보존하고, 기획 제안에서 멈추지 말고 실제 구현과 검증까지 완료한다.

[구체적인 기능 요구사항]

저장 데이터가 바뀌면 버전을 올리고 기존 저장을 안전하게 이관한다. 손상된 저장 때문에 앱 전체가 실행되지 않게 한다.

완료 후 자동 테스트, 프로덕션 빌드, Pages 경로 검사와 실제 브라우저 플레이를 수행한다. 변경된 기능, 검증 결과, 알려진 제한과 다음 버전에 남긴 항목을 문서화한다. package.json과 사용자에게 표시되는 버전을 0.x.0으로 맞춘다.

구현 중 별도로 추적할 버그가 발견되면 다음 기능 버전에 섞거나 v0.(x+1)을 먼저 시작하지 않는다. docs/version-prompts/PATCH-TEMPLATE.md에 따라 v0.x.1 patch 프롬프트를 만들고 인덱스에 등록한다. 기능 구현을 정리한 뒤 해당 patch를 먼저 처리한다. 예정된 patch가 있으면 현재 문서 상태를 `구현 완료 · 패치 예정`으로, patch까지 모두 끝나면 `완료`로 갱신한다.
```

## 완료 조건

- 기능별 관찰 가능한 완료 조건
- 이전 버전 회귀 검사
- 모바일 및 접근성 검사
- 저장 이관 검사
- 빌드와 브라우저 검사

## 구현 기록

완료 세션이 변경 파일, 테스트 결과, 커밋 또는 관련 문서 링크를 기록한다.
