# v0.7.1 — 가트몬 털 질감 정리

- 상태: 완료
- 유형: 시각 수정
- 선행 버전: v0.7
- 제품 버전: `0.7.1`
- 작성일: 2026-09-11

v0.7 저장 관리 검증 중 사용자가 가트몬의 털 질감을 나리와 함께 있는 초상화와 단독 전투 이미지 모두에서 제거해 달라고 요청했다. 기존 자세·얼굴·장갑·꼬리·나리 의상은 유지하고 잔털과 가슴/목의 뾰족한 털을 매끈한 셀 셰이딩으로 수정한다. imagegen으로 두 파일을 편집하고 최적화·매니페스트·출처·브라우저 검증을 완료한다. v0.7의 데이터 관리 작업을 먼저 개별 완료하고 이 추가 시각 패치를 적용한다. v0.8은 진행하지 않는다.

## 구현·검증 기록

- 내장 imagegen으로 나리 동반 초상화와 단독 스프라이트를 각각 편집했다. 가슴·목·몸통의 털 뭉치와 잔털선을 제거하고 매끈한 윤곽과 셀 셰이딩으로 통일했다. 귀 끝·꼬리의 보라색 모양, 얼굴·장갑·자세와 나리 의상은 유지했다.
- `kari-gatomon-smooth.webp` (640×640, 68,960B), `gatomon-smooth-battle.webp` (640×640 알파, 50,588B). 합계 119,548B. 매니페스트를 갱신하고 이전 두 파일은 제거했다.
- 데스크톱 1280×900 및 모바일 390×844에서 상세 초상화와 전투를 육안 확인했다. 캐릭터 전신과 매끈한 몸통, 투명 배경, 크롭/이미지 로딩을 확인했다. 게임 규칙·저장 구조 변경 없음.
- 프롬프트는 `assets/prompts/v0.7.1/`, 제작 출처는 `assets/ATTRIBUTION.md`에 기록했다.

검증: 테스트 82개, 프로덕션 빌드, Pages 경로 검사, 50개 알파 스프라이트 검사, 로컬 HTTP 214 URL 모두 통과. 프로덕션 index.html 직접 접근 후 기존 신나리 전투 이어하기에서도 새 이미지를 확인했다. public/assets 전체 22,284,961B(오디오 두 코덱 포함), 타이틀 초기 리소스 증가는 없다.
