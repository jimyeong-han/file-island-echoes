# v0.6.2 — 가트몬 단독 전투 이미지 자세 수정

- 상태: 완료
- 유형: 버그 수정
- 선행 버전: v0.6.1
- 제품 버전: `0.6.2`
- 작성일: 2026-09-11

사용자가 v0.6.1 검수 중 수정 대상은 신나리와의 초상화가 아니라 가트몬 단독 이미지라고 정정했다. 단독 전투 스프라이트의 머리·목·어깨·몸통 방향과 발의 접지를 자연스럽게 다시 구성한다. 현재 초상화의 나리 숏컷과 의상은 유지한다.

imagegen으로 프로젝트 자체 에셋만 편집한다. 전투·지도·공명·진화·도감의 공통 매니페스트에서 새 이미지를 사용하고 알파·가장자리·크롭·작은 표시 크기를 확인한다. 전투 규칙·저장 구조를 변경하지 않는다. 테스트·빌드·Pages 경로와 실제 브라우저 검증 후 v0.7로 넘어간다.

## 구현 기록

구현 시작 기준 `c3ddc2f`. `characters/gatomon-balanced-battle.webp`(640×640 알파 WebP)로 교체. 머리·어깨·가슴과 발 방향을 새로 구성했다. 공명은 같은 art ID를 사용한다. 1280px 로컬 전투 fixture와 390px 프로덕션 새 탐험 → 신나리 → 전투에서 교체·크롭·배경 투명을 확인했다. 50개 알파 스프라이트 감사, 테스트 53개, build/check:pages/로컬 HTTP 214 URL 통과.
