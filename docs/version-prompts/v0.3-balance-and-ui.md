# v0.3 — 전투 밸런스와 탐험 UI

- 상태: 완료
- 선행 버전: v0.2
- 제품 버전: `0.3.0`
- 구현 기준: `dfff45a`

## 목표

공격 카드만 사용해도 쉽게 완주되던 전투를 조정하고, 적의 위협과 경로 선택을 읽으며 방어·정화·회복을 판단하는 덱빌딩 게임으로 다듬는다.

## 다른 세션에 전달할 프롬프트

```text
File Island Echoes v0.2를 실제로 플레이하고 v0.3 전투 밸런스와 탐험 UI를 개선해줘. 기존 진화·저장·도감·팬 에셋은 유지하되 무료 에너지, 반복 회복, 전투 후 자동 회복 때문에 공격 일변도로 완주되는 원인을 측정하고 조정한다.

적의 다음 행동 수치, 플레이어 방어, 상태 이상과 파트너 반동을 합친 예상 피해를 손패 사용 후마다 갱신해 보여준다. 보스는 장기전에서 단계적으로 강해지되 강화 일정과 현재 보너스를 명확히 표시한다. 흡수는 실제로 체력에 들어간 피해를 기준으로 처리한다.

일반 진화는 안정적인 운영, 스컬그레이몬은 높은 순간 화력과 반동이라는 차이를 유지한다. 강제 진화는 항상 경고와 직접 확인을 거친다. 카드 비용·회복량·보급·휴식·적 체력과 패턴을 함께 조정하고 첫 전투는 규칙 학습이 가능해야 한다.

고정 시드 기반 밸런스 시뮬레이션을 만들어 경로, 진화체와 공격/전술 전략을 반복 비교한다. 자동 전략의 승률을 사람의 승률로 표현하지 않는다. 양쪽 진화 경로에 실제 승리 가능성이 있으면서 방어와 상태 관리의 차이가 결과에 나타나게 한다.

지도, 전투와 손패가 1280×900 화면에서 한눈에 읽히도록 높이와 정보 구조를 다듬고, 320px와 390px 모바일에서 가로 넘침 없이 카드 선택과 대상 선택이 가능하게 한다. 자동 테스트, 밸런스 측정, 프로덕션 빌드, Pages 경로 검사와 실제 브라우저의 정상/강제 진화 플레이를 문서화한다.
```

## 완료 기준

- 공격 일변도와 전술적 플레이의 결과 차이가 재현 가능한 측정에 나타난다.
- 적 예고와 실제 피해, 흡수와 보스 강화가 일치한다.
- 두 진화 경로, 저장 복원과 모바일 전투가 회귀 없이 동작한다.
