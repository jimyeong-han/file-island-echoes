# v0.15.1 — 애니메이션 고도화

- 상태: 예정
- 유형: 시각·사용성 개선 패치
- 선행 버전: v0.15
- 제품 버전: `0.15.1`

## 목표

v0.12의 스킬별 전투 이펙트와 v0.13의 디지바이스 진화 연출을 실제 플레이 화면에서 점검하고, 움직임의 자연스러움과 타격감·완성도를 높인다. 웹과 모바일에서 가볍게 작동하고 플레이 속도를 유지한다.

## 다른 세션에 전달할 프롬프트

```text
File Island Echoes v0.15.1 애니메이션 고도화 패치를 진행해줘. AGENTS.md, 버전 프롬프트와 Git 상태, docs/v0.12-validation.md, docs/combat-effect-map.md, docs/v0.13-validation.md, 전투 이펙트·MotionQueue·진화 시퀀스·오디오 및 PWA 코드를 먼저 확인하고 기존 사용자 변경을 보존한다.

1. 먼저 실제 게임에서 플레이어 공격·적 공격·피격·방어·카드 사용/드로우·진화·화면 전환을 살펴본다. 정지 화면만으로 판단하지 말고 움직임과 오디오를 재생해 끊김, 대상과 이펙트 분리, 지나치게 기계적인 확대/이동, 부자연스러운 접지, 타이밍 불일치, 정보 가림을 기록한다. v0.12의 기술별 매핑과 v0.13의 일반/강제/공명 진화를 기준으로 개선 우선순위를 정하고 전후 비교 가능한 장면을 확보한다.

2. 전투에서는 예비 동작 → 공격 궤적 → 적중 → 피격 반응 → 복귀의 흐름을 다듬는다. 스킬별 실루엣과 속성 차이를 유지하면서 출발점·방향·대상 접지점과 이펙트가 일치하도록 조정한다. 실제 판정에 맞는 단일·광역·다단 타격, 방어 및 0 피해, 적 공격의 반응을 구분하고 이펙트·사운드·체력 변화가 같은 적중 시점에 맞게 한다. 플레이어·적의 다양한 크기와 다수 대상에서 링, 캐릭터 및 행동 예고가 가려지거나 어긋나지 않도록 한다.

3. 진화에서는 디지바이스 점등, 신호 전달, 이전 모습의 전환, 진화체 등장, 음악의 고조가 매끄럽게 이어지도록 한다. 일반 진화·강제 진화·빛의 공명 각각의 성격과 각 파트너의 전후 모습이 구분되게 하고, 과도한 번쩍임이나 길어진 대기 없이 기존 건너뛰기 및 결과 설명을 유지한다. 스프라이트를 임의로 변형해 인체나 캐릭터 외형이 어색하게 찌그러지지 않도록 한다.

4. 카드 배분·뒤집기·사용·턴 종료 등 기존 UI 모션도 전투 템포에 맞게 정돈한다. 애니메이션이 늘어날수록 입력이 느리게 느껴지지 않게 하고, 이미 처리된 판정과 연출 순서를 분리해 중복 공격이나 턴 진행이 발생하지 않도록 한다. 전투 UI에 상시 설명 문구를 추가하지 않는다.

5. 기존 2D 에셋과 CSS/SVG/Canvas 등 프로젝트 구조를 우선 활용하고 꼭 필요한 경우에만 경량 신규 에셋을 제작한다. 무분별한 흔들림, 빠른 섬광, 화면 전체를 덮는 효과, 대형 라이브러리 추가를 피한다. 기존 효과음·음악과 음소거 설정을 지키고, 움직임 줄이기와 prefers-reduced-motion에서는 필수 적중·결과 정보만 짧고 명확하게 보여준다. 키보드와 스크린리더 조작, 진화 건너뛰기를 유지한다.

6. 연출 중 화면 이동, 백그라운드 전환, 재접속, 타깃 사망, 연속 입력과 PWA 업데이트에 따른 취소·정리를 확인한다. 전투 수치·카드 판정·난수·진화 조건, 캐릭터별 저장 및 계정 동기화는 바꾸지 않는다. 진화 효과는 건너뛰기·재진입에도 한 번만 적용한다.

7. 최소한 불꽃 투사체, 근접 발톱, 전기, 덩굴, 광역, 다단, 적 공격, 방어/무피해, 일반 진화, 강제 진화, 공명 진화를 전후 비교한다. 전체 기존 스킬 매핑 누락과 실제 피해 대상 일치도 자동 검사한다. 320px, 390×844, Galaxy S23+ CSS viewport 및 데스크톱에서 일반/감소 모션, 음소거, 터치·키보드와 오프라인 PWA를 확인한다. 모바일 저사양을 고려해 프레임 드롭과 입력 지연을 관찰하고 측정 환경을 기록한다. 실기기가 없으면 에뮬레이션 결과와 구분한다.

npm test, npm run build, 관련 Pages/Vercel 및 PWA 검사를 실행한다. 개선 전후 영상 또는 연속 프레임, 대표 장면별 변경·타이밍·성능·접근성·회귀 결과를 docs/v0.15.1-validation.md에 기록한다. package.json과 화면 버전을 0.15.1로 맞추고 프롬프트 상태·버전 목록을 갱신한다. 저장 구조에 변화가 없다면 schema version은 유지한다.
```

## 완료 조건

- 전투와 진화의 동작·이펙트·사운드가 자연스럽게 연결되고 대표 장면의 전후 비교가 가능하다.
- 스킬별 특성, 실제 판정 및 모든 기존 진화 경로가 유지된다.
- 모바일 성능, 접근성, 건너뛰기·취소 및 저장·PWA 회귀 결과가 기록된다.
