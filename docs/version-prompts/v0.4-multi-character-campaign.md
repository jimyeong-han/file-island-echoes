# v0.4 — 8명 캐릭터와 캠페인 확장

- 상태: 완료
- 선행 버전: v0.3
- 제품 버전: `0.4.0`
- 구현 기준: `6d0abea`

## 목표

선택받은 아이 8명을 모두 플레이 가능하게 하고, 문장별 고유 능력·전용 덱·진화·개인 사건을 3개 챕터와 원작 1세대 적 풀에 결합한다.

## 다른 세션에 전달할 프롬프트

```text
File Island Echoes v0.3을 v0.4로 확장해 신태일/아구몬, 매튜/파피몬, 한소라/피요몬, 장한솔/텐타몬, 이미나/팔몬, 정석/쉬라몬, 리키/파닥몬, 신나리/가트몬 중 한 팀을 선택해 플레이하게 해줘. 8명은 처음부터 선택 가능해야 하며 선택 화면에서 문장, 지속 능력, 전투당 한 번 쓰는 문장 능력, 덱 키워드, 난이도와 진화를 설명한다.

용기는 위험 보상 공격, 우정은 카드 연계와 보존, 사랑은 보호와 부담 관리, 지식은 분석과 덱 조작, 순수는 정화와 개화, 성실은 자원 비축, 희망은 제한된 역전, 빛은 강화 제거와 오염 정화를 중심으로 설계한다. 각 팀에는 공용 카드 외에 전용 카드 5~7종과 실제로 다른 시작 덱을 제공한다.

원작의 파트너 진화를 구현한다. 가트몬은 성숙기 시작 설정을 유지하고, 중간에는 새 공식 진화체를 만들지 말고 빛의 공명이라는 능력 강화 단계를 거쳐 엔젤우몬으로 진화한다. 아구몬에는 경고 후 선택하는 스컬그레이몬 경로를 유지한다.

공통 사건 안에 캐릭터별 도입, 전용 이벤트 세 개 이상, 문장을 시험하는 선택, 파트너 대화, 보스 직전 장면과 개인 엔딩을 넣는다. 선택은 유대·부담·진화 에너지·덱과 다음 경로에 실제 영향을 준다.

파일섬/데블몬, 서버대륙/에테몬, 현실 세계/묘티스몬의 세 챕터를 각각 10~15분 단위로 구성한다. 원작 1세대에 등장한 일반 적 16종 이상, 강적 4종 이상, 챕터 보스 3종 이상과 이벤트·지원 디지몬 4종 이상을 추가한다. 검은 톱니바퀴에 조종된 디지몬은 악역으로 단정하지 않고 승리를 정화로 서술한다.

캐릭터, 파트너, 문장, 카드, 진화, 적, 챕터와 이야기를 데이터로 분리한다. RunState에는 선택 캐릭터·진화·덱·문장 상태·개인 이야기 플래그를 저장하고 ProfileState에는 캐릭터별 클리어·도감·엔딩을 저장한다. v1 저장은 신태일/파일섬 기준의 새 스키마로 안전하게 이관한다.

기존 화풍에 맞는 신규 팬 에셋을 만들고 필요한 화면에서만 지연 로드한다. 8명 모두로 세 챕터를 완주할 수 있는지 자동 전략과 실제 브라우저로 검증한다. 캐릭터 상태 혼입, 능력 설명과 실제 동작, 개인 이벤트, 저장 복원, 모바일 UI, 빌드와 Pages 경로를 확인하고 콘텐츠·밸런스·원작 등장 확인 자료를 문서화한다.
```

## 완료 기준

- 8명의 덱, 능력, 진화와 개인 서사가 실제 플레이에서 구분된다.
- 세 챕터와 확장된 적 풀이 선택 캐릭터별로 완주 가능하다.
- 구버전 저장 이관과 캐릭터별 진행 기록이 안전하게 동작한다.
