# v0.12 — 스킬별 공격·피격 이펙트

- 상태: 완료
- 유형: 기능 버전
- 선행 버전: v0.11 및 선행 patch
- 제품 버전: `0.12.0`
- 작성일: 2026-11-06

## 구현 기록

2026-11-06 구현. 39개 공격 카드와 39개 적 공격에 기술별 시전·이동·적중·실제 피해 반응을 연결했다. 사용자의 시전 품질 피드백을 반영해 공통 원을 제거하고 13종의 시전 실루엣과 동작을 적용했다. 175개 테스트, 608개 엔진 비교, 빌드·Pages·HTTP 및 Codex 앱 내 브라우저 일반/감소 모션 전수 검증을 통과했다. [검증 기록](../v0.12-validation.md), [ID 매핑](../combat-effect-map.md). 저장 schema와 판정은 유지했다.

## 목표

현재 공통 공격 표시와 단순한 흔들림 위주의 전투 연출을 개선한다. 각 공격 스킬의 성격이 시전부터 적중까지 드러나고, 공격받은 디지몬도 해당 스킬에 어울리는 피격 반응을 보이게 한다.

## 다른 세션에 전달할 프롬프트

```text
File Island Echoes에 v0.12 스킬별 전투 이펙트를 구현해줘. 먼저 AGENTS.md, 버전 프롬프트 목록, 현재 Git 상태, 카드·적 행동 데이터, 전투 렌더링, MotionQueue, 오디오와 v0.9.1 대상 링 구현을 살펴본다. v0.11 및 그 이전 예정 patch가 끝나지 않았다면 버전 순서대로 먼저 완료한다. 기존 사용자 변경사항을 보존한다.

1. 현재 실제로 사용 가능한 모든 공격 카드와 적 공격 행동을 ID별로 조사해 목록화한다. 각 항목의 공격 주체, 대상, 단일/전체 대상 여부, 속성, 효과음, 타격 횟수를 정리한다. 플레이어의 각 공격 스킬과 적의 각 공격 행동에 시전·이동 또는 발사·적중·피격 반응을 명시적으로 연결하고 누락이 없도록 한다. 공통 구성요소를 재사용해도 되지만 각 스킬은 형태·색·방향·타이밍·타격 패턴 조합에서 구분되어야 한다. ID별 매핑과 커버리지를 문서화하고 없는 매핑은 안전한 기본 효과를 사용한다.

2. 스킬의 의미를 살려 연출한다. 예를 들어 베이비 플레임은 작은 불꽃 발사와 불꽃 충격, 기가 디스트로이어는 복수 발사체와 광역 충격, 전기 충격은 번개와 전기 스파크, 덩굴 기술은 뻗는 덩굴과 조임, 물 기술은 물줄기와 물보라, 네코 펀치는 발톱 궤적, 홀리 애로우는 빛 화살과 섬광으로 구분한다. 이는 방향 예시이며 실제 카드 데이터와 원작 분위기, 기존 에셋을 확인해 나머지 모든 스킬에도 어울리는 고유 연출을 설계한다. 근접 공격, 투사체, 광역, 다단 공격의 시각적 차이를 명확히 한다.

3. 실제 공격자와 대상의 현재 위치를 기준으로 이펙트를 그린다. 피격 위치에서 충격, 짧은 반응과 체력 변화가 자연스럽게 맞물리게 하고, 광역 공격은 실제 영향을 받은 모든 적에게 적용한다. 방어에 막히거나 피해가 0인 경우 방어 반응을 보여 주며 피해를 입지 않은 대상에게 거짓 피격 반응을 주지 않는다. 적의 공격도 플레이어 쪽에 맞는 발사·피격 효과를 제공한다. 선택 링과 스프라이트, 체력·행동 예고를 가리지 않고 카메라 스크롤이나 화면 크기에 따라 위치가 어긋나지 않게 한다.

4. 카드 사용, 기존 사운드, 적 행동, 실제 상태 변경과 이펙트의 순서를 동기화한다. 연출은 전투 판정과 난수, 저장 결과를 바꾸지 않으며 연출 중 입력 중복·턴 중복을 막는다. 빠른 화면 전환, 백그라운드 전환, 대상 사망, 전투 종료, 애니메이션 취소 시 잔상과 타이머를 정리한다. 저장·불러오기와 PWA 업데이트 후 전투를 이어도 상태가 바뀌지 않게 한다.

5. 기존 게임의 그림과 어울리는 완성도 높은 2D 연출을 만든다. SVG, CSS, Canvas 등 가벼운 방법과 필요한 자체 제작 에셋을 적절히 사용한다. 모바일에서도 자연스럽게 보이도록 크기와 속도를 조정하고 과도한 번쩍임, 화면 전체 흔들림, 긴 대기, 큰 다운로드를 피한다. 원작 에셋을 그대로 복사하지 않는다. 효과음은 기존 믹서와 음소거 설정을 따른다. 움직임 줄이기 및 시스템 reduced-motion에서는 짧고 정적인 적중 표시로 대체하고 필수 정보는 전달한다.

6. 카드 ID별 연출 매핑 전수 검증과 단일/광역/다단, 방어·무피해, 적 공격, 피격·사망, 취소와 재진입 자동 테스트를 추가한다. 8명 캐릭터의 기본·진화 기술, 서로 다른 크기의 적과 보스, 2명 이상 적을 실제 브라우저에서 확인한다. 320px, 390×844, Galaxy S23+ CSS viewport와 데스크톱에서 스크린샷 또는 영상으로 시전·적중을 확인하고 성능·입력 지연·오디오 동기화와 reduced-motion을 검증한다. 실기기 미검증 항목은 명시한다. npm test, npm run build, npm run check:pages를 실행한다.

각 스킬 ID와 시각 요소·타격 타이밍·효과음의 매핑, 에셋 출처, 접근성 및 검증 결과를 docs/v0.12-validation.md에 기록한다. package.json과 표시 버전을 0.12.0으로 맞추고 버전 프롬프트 상태와 관련 문서를 갱신한다. 저장 구조가 바뀌지 않으면 schema version은 올리지 않는다.
```

## 완료 조건

- 실제 사용 가능한 각 공격 스킬과 적 공격 행동에 구별 가능한 시전·적중·피격 연출이 연결된다.
- 단일·광역·다단 공격과 방어·무피해 반응이 실제 전투 결과와 일치한다.
- 전투 판정·저장·오디오·대상 선택이 유지되고 모바일과 움직임 줄이기에서 정상 작동한다.
- 스킬별 매핑, 누락 검사와 브라우저 검증 결과가 기록된다.
