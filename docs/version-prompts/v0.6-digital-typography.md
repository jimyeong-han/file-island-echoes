# v0.6 — 디지털 모험 타이포그래피와 신나리 연령 표현

- 상태: 예정
- 유형: 기능 버전
- 선행 버전: v0.5.1
- 제품 버전: `0.6.0`
- 작성일: 2026-09-10

## 목표

현재 시스템 글꼴 중심의 화면을 File Island Echoes의 디지털 모험 분위기에 맞는 한글 타이포그래피로 교체한다. 제목과 숫자에는 개성을 주고, 카드·대사·설정의 본문은 작은 모바일 화면에서도 빠르게 읽히게 한다. 같은 비주얼 정리 범위에서 성숙하게 표현된 신나리 초상화를 원작 시점의 어린 연령대로 수정한다.

## 다른 세션에 전달할 프롬프트

```text
현재 저장소의 File Island Echoes를 v0.6으로 업데이트해 전체 폰트와 타이포그래피를 디지털 모험 게임의 분위기에 맞게 개선하고, 신나리 일러스트의 연령 표현도 함께 수정해줘.

먼저 AGENTS.md, docs/version-prompts/README.md, v0.5.1 문서, 현재 CSS와 모든 화면, Git 상태를 확인한다. v0.5.1이 완료되지 않았다면 해당 patch를 먼저 처리한다. 기존 사용자 변경사항을 보존하고 게임 규칙과 콘텐츠는 변경하지 않는다.

공식 디지몬 로고나 공식 게임의 전용 서체를 복제하지 않는다. 한글을 완전하게 지원하고 웹 재배포가 허용된 오픈 라이선스 폰트만 사용한다. 공식 배포처에서 라이선스를 확인하고 저장소에 라이선스 파일과 출처를 기록한다. 외부 CDN에 의존하지 말고 필요한 WOFF2 파일을 프로젝트에 포함한다.

폰트 역할을 최소 두 계층으로 나눈다.
- Display: 타이틀, 챕터명, 진화명, 보스명, 큰 버튼과 짧은 강조 문구. 각지고 디지털적인 인상을 주되 한글 자소가 깨지지 않아야 한다.
- Body: 카드 설명, 대사, 설정, 도움말, 도감과 긴 문장. 높은 가독성과 분명한 숫자·기호 구분을 우선한다.
- 필요할 때만 Numeric/Mono 역할을 추가해 HP, 에너지, 피해량과 상태 수치를 정렬한다. 폰트 수와 다운로드를 불필요하게 늘리지 않는다.

현재 프로젝트에 어울리는 후보를 실제 렌더링으로 비교한 뒤 선택한다. Galmuri, Pretendard 등은 후보일 뿐이며 이름만 보고 결정하지 않는다. 선택한 폰트의 한글 글리프 범위, 라이선스, WOFF2 용량, 굵기와 모바일 가독성을 확인한다.

다음 화면을 모두 점검하고 역할별 스타일을 적용한다.
- 타이틀과 메뉴
- 캐릭터 선택 및 상세
- 챕터 선택과 탐험 지도
- 카드 이름·비용·설명
- 전투 HUD와 적 행동 예고
- 문장 능력과 상태 효과
- 이벤트 대화와 선택지
- 진화, 결과와 엔딩
- 도감, 설정, 도움말, 크레딧
- 오디오 설정과 오류·안내 메시지

CSS custom property로 폰트 역할을 중앙 관리한다. 예: --font-display, --font-body, --font-numeric. 컴포넌트마다 font-family 문자열을 반복하지 않는다. font-display: swap 또는 프로젝트에 적절한 로딩 전략을 사용하고, 폰트 로드 실패 시 한글이 깨지지 않는 시스템 fallback을 제공한다.

다음 타이포그래피 문제도 함께 조정한다.
- 한글 단어 중간 줄바꿈과 고아 글자
- 제목의 과도한 letter-spacing
- 작은 카드에서의 행간과 글자 크기
- 굵기만으로 구분되지 않는 정보 위계
- 숫자 0/8, 1/7과 +/− 기호 구분
- 버튼 라벨의 잘림
- 영어 고지와 한국어 본문의 혼용
- 브라우저 글자 확대 200%에서의 겹침과 넘침

전체 한글 폰트 파일이 지나치게 크면 공식 서브셋 방식 또는 필요한 굵기 축소를 검토한다. 실제 게임에 쓰이는 문자가 빌드 후 누락되지 않게 한다. 동적 캐릭터명, 카드명, 적 이름과 도감 설명 때문에 단순 정적 문자열 스캔만으로 무리하게 글리프를 제거하지 않는다.

같은 버전의 비주얼 정리로 현재 `portraits/kari-gatomon.webp`도 수정한다. 먼저 현재 이미지를 view_image로 원본 해상도에서 확인하고, 얼굴 비율·턱선·눈 크기·어깨 폭·신장 비례·자세와 표정 중 어떤 요소가 성숙하게 보이는지 기록한다.

imagegen 스킬과 이미지 생성 도구를 사용해 기존 셀 셰이딩 팬 일러스트와 같은 화풍으로 다시 만든다. 신나리는 초등학교 저학년 정도로 보이는 둥글고 짧은 얼굴, 부드러운 턱선, 큰 머리 비율과 작은 어깨·체구를 가져야 한다. 차분하고 다정하지만 어린 표정을 사용한다. 과한 화장, 성인 체형, 패션 화보 포즈, 성적 대상화로 보일 수 있는 구도와 신체 강조를 사용하지 않는다. 영아처럼 과장하거나 다른 아이보다 비정상적으로 작게 만들지도 않는다.

가트몬의 크기와 품질, 다른 일곱 초상화의 카메라 거리·조명·외곽선·명암과 색 보정을 유지한다. 공식 애니메이션 캡처나 게임 이미지를 다운로드·트레이싱하지 않고, 특정 공식 장면의 자세와 구도를 복제하지 않는다. 이미지 안에 글자, 로고, 서명과 워터마크를 넣지 않는다.

캐릭터 선택, 상세, 개인 스토리, 엔딩, 도감과 모바일 크롭에서 새 초상화를 확인한다. 단순히 기존 이미지를 축소해 어린 것처럼 보이게 하지 않는다. WebP로 최적화하고 `src/asset-manifest.json`, `ASSETS.md`와 `assets/ATTRIBUTION.md`를 갱신한다.

검증:
- 1280×900, 390×844, 320×740 화면에서 모든 주요 화면 확인
- 카드와 적 예고의 숫자·한글 가독성 확인
- 긴 캐릭터 능력명과 이벤트 선택지 줄바꿈 확인
- 브라우저 글자 크기 또는 확대 200% 확인
- 폰트 파일 404, CORS와 MIME 확인
- 네트워크 차단 또는 폰트 로드 실패 시 fallback 확인
- 다른 일곱 캐릭터와 나란히 비교해 신나리만 성인처럼 보이지 않는지 확인
- 캐릭터 선택·상세·스토리·엔딩·도감에서 신나리와 가트몬 크롭 확인
- 신나리 이미지의 생성 오류, 404, 캐시 경로와 WebP 용량 확인
- npm test, npm run build, npm run check:pages
- 기존 v0.5.1 오디오 입력 반응과 버튼 조작 회귀 확인

package.json과 사용자에게 표시되는 버전을 0.6.0으로 맞춘다. README 또는 별도의 타이포그래피 문서에 사용 폰트, 역할, 라이선스, 파일 용량과 교체 방법을 기록한다. docs/version-prompts/v0.6-digital-typography.md의 상태를 완료로 바꾸고 구현 기준을 추가한다.
```

## 완료 조건

- 제목·본문·수치의 역할이 일관되고 한글이 모든 화면에서 읽힌다.
- 폰트가 로컬 WOFF2와 적법한 라이선스 기록을 가진다.
- 신나리가 다른 선택받은 아이와 비교해 초등학생 연령대로 자연스럽게 보이고 가트몬과 기존 화풍이 유지된다.
- 모바일, 200% 확대와 fallback에서 핵심 조작이 깨지지 않는다.
- v0.5.1을 포함한 기존 기능과 빌드 검사가 회귀하지 않는다.
