# v0.1 — 기본 웹게임 프로토타입

- 상태: 완료
- 선행 버전: 없음
- 제품 버전: `0.1.0`
- 구현 기준: `1d9ef9b`

## 목표

디지몬 어드벤처의 파일섬을 배경으로, 신태일과 아구몬이 10~15분 동안 노드 탐험·카드 전투·진화·데블몬전을 경험하는 정적 웹게임을 만든다.

## 다른 세션에 전달할 프롬프트

```text
현재 저장소에 File Island Echoes의 플레이 가능한 첫 버전을 구현해줘. 1999년 TV 애니메이션 디지몬 어드벤처의 파일섬과 등장인물을 바탕으로 한 비공식·비영리 팬 프로토타입이다.

TypeScript와 Vite를 기본으로 사용하고 데스크톱과 모바일 브라우저에서 실행되게 한다. 타이틀 → 노드 지도 → 일반/강적/이벤트/휴식 → 카드 보상 → 진화 → 데블몬 보스 → 결과로 이어지는 한 판을 완성한다. 한 판은 약 10~15분, 약 10~12개 노드와 5~6회의 전투로 구성한다.

전투는 턴마다 에너지 3, 카드 5장 드로우, 손패 버림, 버린 더미 재순환, 적 행동 예고, 다음 플레이어 턴의 방어 초기화를 지원한다. 시작 덱 약 10장, 카드 15~18종, 적 5~6종과 데블몬을 구현한다. 카드 보상은 세 장 중 한 장 선택 또는 건너뛰기다.

육성 수치는 진화 에너지, 유대, 부담으로 나눈다. 아구몬 → 그레이몬 → 메탈그레이몬을 구현하고, 높은 부담에서 사용자가 위험을 확인한 뒤 선택하는 스컬그레이몬 강제 진화도 구현한다. 진화는 이미지와 능력치뿐 아니라 카드와 전투 방식도 변경한다.

새로고침 후 이어하기, 도감·클리어 기록·설정의 영구 저장과 손상 저장 복구를 localStorage로 구현한다. 데이터와 전투 규칙을 화면 코드에서 분리한다. GitHub Pages의 /file-island-echoes/ 경로에서 정적 배포 가능하게 하고 noindex 메타데이터와 비공식 팬 프로젝트 고지를 제공한다. 공식 추출 이미지·음원·로고는 사용하지 않는다.

실제 플레이로 새 탐험부터 승리와 패배까지 확인하고, 카드·에너지·방어·적 예고·두 진화 경로·저장 복원·모바일 조작·프로덕션 빌드를 검증한다. 실행 방법과 검증 결과를 문서화한다.
```

## 완료 기준

- 아구몬으로 탐험을 시작해 데블몬전의 승패까지 진행할 수 있다.
- 메탈그레이몬과 스컬그레이몬 경로가 전투에 반영된다.
- 모바일 조작, 체크포인트 저장과 Pages 프로젝트 경로가 동작한다.
