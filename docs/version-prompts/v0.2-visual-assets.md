# v0.2 — 비주얼 에셋 개선

- 상태: 완료
- 선행 버전: v0.1
- 제품 버전: `0.2.0`
- 구현 기준: `578e8fe`

## 목표

임시 도형과 낮은 품질의 에셋을 일관된 팬 일러스트로 교체하고, 모든 주요 화면을 실제 게임처럼 읽히는 반응형 구성으로 개선한다.

## 다른 세션에 전달할 프롬프트

```text
File Island Echoes v0.1을 실행해 모든 화면과 에셋을 점검한 뒤 v0.2 비주얼을 구현해줘. imagegen을 사용할 수 있으면 래스터 캐릭터·배경 제작에 사용하고, 게이지·버튼·아이콘은 CSS 또는 SVG로 선명하게 만든다.

짙은 남색, 밝은 청록, 따뜻한 주황을 중심으로 깨끗한 외곽선과 강한 실루엣을 가진 2D 셀 셰이딩 게임 아트로 통일한다. 데이터 격자, 깨진 픽셀, 스캔라인, 홀로그램과 원형 인터페이스를 보조 모티프로 사용한다. 이미지 안에 글자나 로고를 생성하지 않는다.

아구몬·그레이몬·메탈그레이몬·스컬그레이몬·데블몬과 현재 적의 투명 전투 이미지를 만들고, 숲·공장·무한산·보스전 배경을 제작한다. 타이틀, 지도, 전투, 이벤트, 카드 보상, 진화, 결과와 도감 화면을 같은 아트 방향으로 다듬는다. 이모지를 핵심 아이콘으로 사용하지 않는다.

공식 애니메이션 캡처, 공식 게임 추출물, 로고와 음원을 사용하지 않는다. 독자적인 포즈와 구도로 새로 제작한다. 캐릭터는 알파 WebP/PNG, 배경은 WebP, UI 아이콘은 SVG를 사용하고 실제 표시 크기에 맞게 최적화한다. 에셋 경로는 중앙 매니페스트로 관리하고 제작 방식과 교체 위치를 attribution 문서에 기록한다.

데스크톱과 390px/320px 모바일 화면을 실제로 확인하고 캐릭터 크롭, 카드 가독성, 터치 영역, 가로 넘침과 에셋 404를 수정한다. 프로덕션 빌드와 Pages 경로 검사를 통과시킨다.
```

## 완료 기준

- 핵심 캐릭터, 적과 네 가지 지역이 일관된 화풍으로 표시된다.
- 모바일과 데스크톱에서 카드와 전투 정보가 읽힌다.
- 에셋 출처·용량·교체 방법과 브라우저 검증이 문서화된다.
