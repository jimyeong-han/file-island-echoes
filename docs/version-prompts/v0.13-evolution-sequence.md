# v0.13 — 디지바이스 진화 연출과 음악

- 상태: 완료
- 유형: 기능 버전
- 선행 버전: v0.12 및 선행 patch
- 제품 버전: `0.13.0`

## 다른 세션에 전달할 프롬프트

```text
File Island Echoes에 디지바이스를 통한 진화 애니메이션과 진화 전용 음악을 추가해줘. 먼저 AGENTS.md, 버전 프롬프트, 현재 Git 상태, 진화 판정·화면·CSS, audio-events.ts, 오디오 제작·캐시 및 캐릭터별 저장 구조를 확인한다. v0.12와 이전 patch를 완료한 뒤 진행하고 기존 사용자 변경사항을 보존한다.

1. 진화 확정 후 선택받은 아이의 디지바이스가 빛나고 신호가 파트너에게 이어져 디지털 데이터와 빛으로 감싸며 이전 모습에서 진화체가 드러나는 연출을 만든다. 기존 진화 화면과 프로젝트에서 제작한 디지바이스풍 아이콘·캐릭터 이미지를 활용하거나 어울리는 자체 에셋을 제작한다. 파트너의 전후 모습과 이름, 문장이 명확히 인지되게 하고 결과 설명과 계속 버튼을 유지한다. 캐릭터 8명, 각 진화 단계, 스컬그레이몬 강제 진화 및 신나리의 빛의 공명까지 현재 실제 경로를 모두 확인한다. 공명은 새로운 종으로 오인되지 않게 별도 연출한다. 강제 진화는 불안하고 어두운 색감을 쓰되 경고와 판정은 유지한다.

2. 원작 진화 BGM에서 느껴지는 고조감과 희망찬 모험 분위기를 모티브로 짧은 오리지널 진화 음악을 제작한다. 기존 녹음·샘플·가사나 알아볼 수 있는 멜로디를 복제하지 않고 독자적인 선율과 구성으로 작곡한다. 원작 곡과 동일한 음악이라고 표시하지 않는다. AUDIO.md에 제작 방식과 출처를 기록한다. 일반 진화 음악과 강제 진화의 어두운 변형을 고려하고, 게임의 기존 오디오 믹서·음량·음소거 및 모바일 첫 입력 정책을 따른다.

3. 디지바이스 점등, 데이터 전환, 진화체 등장과 음악의 고조 지점을 맞춘다. 기존 evolution-start/evolution-forced/evolution-complete 효과음과 중복 재생되지 않게 조정하고, 결과 화면을 떠나면 진화 음악이 멈추고 이전 장면의 음악이 자연스럽게 복귀한다. 사용자가 바로 건너뛸 수 있는 버튼을 제공하고, 건너뛰기·화면 전환·백그라운드 복귀 시 타이머와 오디오가 남거나 중복 재생되지 않게 한다. 진화 결과는 애니메이션 성공 여부와 무관하게 정확히 한 번 적용된다.

4. 모바일 세로·가로에서 디지바이스와 전후 스프라이트가 잘리지 않도록 하며 320px부터 Galaxy S23+와 데스크톱을 확인한다. 움직임 줄이기에서는 깜빡임·빠른 확대를 없애고 짧은 정적 전환과 결과 표시로 대체한다. 과도한 섬광을 피하고 터치·키보드·스크린리더로 건너뛰기와 계속 진행이 가능해야 한다.

5. v0.9.1의 음악 선캐시 정책에 새 음악의 모든 지원 포맷을 포함해 오프라인에서도 재생한다. 오디오 다운로드 실패나 음소거 상태에서도 진화·저장·진행이 막히면 안 된다. 캐릭터 슬롯별 진화 상태, 진화 화면에서 새로고침, 중도 이탈, PWA 업데이트 및 오디오 복귀를 검증한다.

각 경로별 전후 모습, 정상/강제/공명 연출, 음악 시작·종료·건너뛰기, 오프라인 캐시와 reduced-motion을 자동 테스트 및 실제 브라우저에서 확인한다. npm test, npm run build, npm run check:pages를 실행하고 실기기 미검증 여부와 결과를 docs/v0.13-validation.md에 기록한다. package.json과 사용자 표시 버전을 0.13.0으로 맞추고 관련 문서 및 이 프롬프트의 상태를 갱신한다. 저장 구조가 바뀌지 않으면 schema를 올리지 않는다.
```

## 완료 조건

- 디지바이스에서 시작해 파트너의 진화체가 등장하는 연출이 모든 실제 진화 경로에서 작동한다.
- 원작의 분위기를 환기하는 독창적인 진화 음악이 장면과 동기화되고 오프라인에서도 재생된다.
- 건너뛰기, 음소거, 움직임 줄이기, 화면 전환과 저장 복원이 정상 동작한다.
