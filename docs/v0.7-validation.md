# v0.7 구현·검증 기록

2026-09-11. 선행 v0.6.2 (`878d546`). 게임 규칙, 카드, 밸런스, 내부 schema v2는 유지했다.

- JSON 파일 envelope formatVersion 1, UTF-8 들여쓰기 및 날짜 파일명, 1MiB 제한을 추가했다. 기존 validator와 v1 migration을 재사용하며 전체 트리의 깊이·길이·숫자·위험 키를 제한한다. 알 수 없는 실행 필드는 정규화하며 UI 문자열은 escape한다.
- 검증과 미리보기는 저장하지 않는다. 명시적 교체 확인 뒤 단일 setItem 성공 시에만 메모리·화면·오디오 장면을 갱신한다. 실패 시 기존 메모리를 유지한다. 손상된 탐험은 도감·설정과 분리해 복구를 안내한다.
- 전체 초기화는 별도 확인 dialog에서 앱의 v1/v2 키만 제거한다. 다른 origin 데이터에는 접근하지 않으며 같은 origin의 다른 키도 보존한다. 삭제 실패는 오류를 표시하고 이전 키 복원을 시도한다. 저장소 자체가 계속 거부하면 rollback 보장은 불가능하다.
- 파일 읽기 중 취소한 결과는 요청 번호로 무시한다. native dialog의 포커스 제한·Escape, 파일 label, aria-live, 44px 버튼을 사용한다.

## 검증

1. 자동 테스트 82개 통과: 기존 53개 + 저장 파일 29개. 빈 저장/전체 전투 roundtrip, 단일 쓰기, 용량 실패, 초기화 실패·rollback, v1, 잘못된 JSON/app/미래 버전/payload, 위험 키, 숫자·배열·문장·깊이·파일 크기, 손상 run 및 optional 필드 복구. 합성 시작 시각을 고정해 시각 차이로 인한 테스트 불안정을 제거했다.
2. Chromium의 새 localhost:3007에서 합성 데이터만 사용했다. 빈 JSON 547B와 전투·도감·설정 포함 JSON 2942B를 실제 다운로드했다. 다운로드된 payload가 합성 원본과 정확히 일치했다.
3. 신나리 전투(체력 64, 에너지 2, 방어 7, 손패 4), 클리어/엔딩, 음량 42/16/72%, 모션 감소를 불러오고 이어하기에서 확인했다. 초기화 후 실제 다운로드 파일로 다시 복원했으며 새로고침 후 이어하기가 유지되었다.
4. 다른 app 파일은 오류로 거부하고 현재 데이터는 유지했다. 원본 v1 파일의 이관 미리보기와 확정, 손상 run의 도감/설정 보존 경고를 확인했다. 나머지 비정상 파일 및 브라우저 저장소 실패는 자동 테스트로 확인했다.
5. 초기화 취소(Escape)와 최종 확인을 각각 조작했다. 즉시 이어하기가 사라지고 기본 설정으로 돌아왔다. 검사 페이지에서 현재/legacy 키 모두 없고 다른 테스트 키는 `keep`으로 남은 것을 확인했다.
6. 모바일 320px 데이터 모달·미리보기·확인 버튼, 실제 파일 선택기를 검증했다. preview:3006의 프로덕션 index.html 직접 접근·새로고침과 데이터 화면도 확인했다. 실제 Android/iOS 파일 선택기는 미검증이다.
7. `npm run build`, `npm run check:pages`, `node scripts/check-http.mjs http://127.0.0.1:3006/file-island-echoes/` 통과(214 URL). 모든 파일 raw 22,699,755B이며 오디오/대부분의 이미지는 지연 로딩한다. 새 기능에 네트워크 업로드나 추가 외부 리소스는 없다.

실제 사용자 저장 파일은 사용하거나 커밋하지 않았다. 합성 생성기와 로컬 검사 페이지만 저장소에 포함하며 생성 JSON은 ignored test-results에 둔다.
