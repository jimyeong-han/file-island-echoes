# v0.9.0 구현·검증

기준은 v0.8.2 완료 `5a82d14`와 PWA 계획 `6fdde0c`. v0.10은 진행하지 않았다. 상세 운영 정책은 [PWA.md](../PWA.md).

## 구현

- manifest, 일반/마스커블 192/512 PNG와 Apple 180 PNG. 독자적인 기존 디바이스 모티프를 코드로 제작했다. manifest의 상대 id/start_url/scope는 Pages base 아래로 해석된다. favicon, noindex와 비공식 고지 유지.
- 의존성 추가 없는 작은 worker 모듈과 Vite 후처리 빌드. shell 원자적 설치, 설치 빌드와 일치하는 navigation HTML, 해시 JS/CSS와 runtime 콘텐츠 해시, 타 앱 캐시 보존 및 180응답 한도.
- 설정 내 capability 기반 설치, iOS Safari 수동 안내, 업데이트 대기/적용·전투 차단·저장 실패/오프라인 중단·단일 reload. 개발 환경은 worker 미등록.
- HTTP 그림/소리 캐시만 복구. 저장 schema v2, JSON·오디오 재개·게임 엔진을 유지한다. 초기 스크립트 실패의 수동 재시도도 기록을 지우지 않는다.
- 사용자 후속 요청에 따라 터치 7종만 선행 다운로드한다. 압축 데이터 준비와 실제 AudioContext/재생은 분리한다. OGG/MP3 합계 63,235B. 음악 전체는 받지 않는다.

## 자동 결과

- `npm test`: 126개 통과(기존 110 + PWA/터치 16). worker 범위/원자적 실패/navigation/오프라인/404/캐시 정리/180한도/내용 해시, 업데이트 저장·전투 차단·연속 클릭·한 번 reload·설치 감지·터치만 선행 준비를 포함한다.
- `npm run build`, `npm run check:pages` 통과. PWA 64파일 2,623,151B(약 2.50MiB). 음악 제외, 작은 터치 효과음만 예외. JS gzip 59.58kB, CSS gzip 15.92kB.
- 로컬 프로덕션 HTTP 223 URL 정상. manifest/worker/PNG/Apple 아이콘 포함. PNG 실제 크기, purpose, scope/start_url/id, precache 경로와 파일 존재 검사.
- 캐시명 예: `file-island-echoes-shell-0.9.0-a34a6113440c-9bd4ca76`. 등록 URL과 scope는 정확히 `/file-island-echoes/sw.js`, `/file-island-echoes/`.

## 실제 브라우저 결과

- 별도 localhost 3012에서 새 탐험 → 신태일 → 첫 전투 → 카드/문장 사용 → 턴 진행 → 승리/보상까지 직접 조작했다.
- 서버 프로세스를 중단해 origin 전체 연결을 끊은 뒤 reload → 이어하기에서 쉘몬 체력 14/38, 턴1, 사용 완료 문장이 보존됐다. 오프라인 턴 처리도 진행됐다. 최종 빌드에서도 서버 종료 → reload → 동일 보상 3장 복원 확인.
- 구 빌드가 실행 중인 동안 새 빌드를 만들고 설정의 업데이트 확인을 눌렀다. 새 버전 대기 중에도 전투가 유지되며 적용 버튼은 비활성화됐다. 승리 보상에서 적용 → 타이틀 → 이어하기 후 동일 보상/체력/진행 유지. 이전 shell은 제거되고 runtime은 보존됐다. 단일 reload는 브라우저 전환 관찰과 단위 검사로 확인했다.
- 마지막 기록의 shell은 64파일/2,623,151B, runtime은 방문 파일 17개/1,600,124B였다. 초기 설치가 전체 22MB 오디오/아트를 받는 방식이 아님을 확인했다.
- 미캐시 데블몬 이미지를 합성 DOM으로 추가한 상태에서 서버 종료: `unavailable-art` fallback 처리, 게임 유지. 서버 재개 후 같은 에셋을 다시 표시하면 정상 로드. 이 항목은 자연 플레이 보스 도달 검사가 아니라 실제 fallback 이벤트 검사다.
- 설정 캐시 복구 버튼은 runtime만 삭제하며 앱 shell/탐험은 유지한다.
- 390×844 실제 CSS viewport: 상단48px, dialog347px, 가로 넘침 없음. 844×390: dialog670×358px, 화면 내 배치. 320px iframe/문서 글자32px(200%): dialog275px, 내부 가로 넘침 없음, PWA 버튼 높이70/118px. Tab 포커스와 닫기, reduced-motion 설정 유지 확인. 화면은 스크린샷으로 육안 점검했다.
- 터치 지연 비교: 200ms fetch 지연을 넣은 로컬 QA에서 준비 전347ms → 압축 데이터 준비 후77.6ms. 두 경우 새 AudioManager/첫 AudioContext 사용. 실제 스피커 출력 시간은 포함하지 않는다.

## 검증 한계

in-app Chromium에서는 설치 prompt가 제공되지 않았다. 설치 버튼을 허위로 표시하지 않는 것을 확인했으며 Android 설치 대화상자/홈 화면 아이콘 실행, iOS Safari 설치와 standalone, DevTools installability 진단, 실제 노치와 OS 앱 전환/오디오 출력은 미검증이다. CSS viewport·동작 단위 테스트가 실기기를 대신한다고 주장하지 않는다. 네트워크 단절은 검증 origin 서버 종료로 재현했으며 OS 비행기 모드에서 navigator.onLine 변경을 직접 측정한 것은 아니다. 200%는 rem 확대이며 브라우저 페이지 줌 전체와 다르다.
