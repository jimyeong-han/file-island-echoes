# v0.13 · 디지바이스 진화 연출 검증

2026-11-06 · 제품 버전 0.13.0 · schema 3 유지.

## 구현

- `EvolutionSequence`는 게임 상태를 참조하거나 수정하지 않는 연출 타이머다. 기존 `evolve`가 비용·형태·덱·체력을 한 번 적용하고 저장한 뒤 시작한다. 복원된 진화 화면은 재생 없이 결과만 표시한다.
- 디지바이스와 각 아이의 문장, 신호 선, 이전 모습·데이터 실루엣·새 모습, 전후 이름과 결과 설명. 일반·강제·공명 세 가지 색/동작 처리. 가트몬 공명은 같은 이미지와 별도 설명을 유지한다.
- 5.6초 오리지널 음악 2곡, OGG/MP3 4개 합계 175,317 bytes. 디코딩 완료와 연출 시계가 함께 시작하며 250ms가 지나면 음악 없이 진행한다. 세부 출처/악보는 AUDIO.md와 scripts/compose-evolution.py.
- 음악은 Music 버스로 재생하며 기존 진화 징글/완료 효과와 중복하지 않는다. 즉시 건너뛰기, 다른 화면/모달, 백그라운드, reduced-motion 전환이 타이머와 음악을 취소한다. 감소 모션은 음악 없이 180ms 정적 전환이다.
- 진화 시작 시 화면을 해당 장면으로 스크롤한다. 건너뛰기는 Enter로도 작동하고 계속 버튼으로 포커스를 옮긴다.

## Codex 앱 내 브라우저

`qa/evolution-fixture.ts`의 로컬 합성 체크포인트를 사용해 8명 × 2단계 + 스컬그레이몬 = 17개 실제 진화 경로를 재생했다. 일반/움직임 줄이기 모두 ALL PASS. 각각 단계 전환, 전후 이미지, 비용, 저장된 결과, 남은 음악/타이머를 검사했다. 모든 경로를 자연 탐험으로 해금했다고 주장하지 않는다. QA 코드는 배포 엔트리에 없다.

- 0/900/1800/3400ms 중도 취소, 지도 음악 복귀, 강제 진화 중 타이틀 이탈과 저장 결과 유지 PASS.
- 실제 Enter 입력으로 건너뛰기 → complete/계속 버튼 포커스 확인.
- 320×740, 390×844, 384×832, 1280×900, 844×390. 문서 가로 넘침 없음. 세로/가로 모두 이미지 자체를 자르지 않고 contain으로 표시한다. 작은 화면의 긴 결과는 세로 스크롤로 확인한다. 스크린샷 `test-results/v0.13-*.jpg`는 로컬 전용.
- 첫 감소 모션 QA는 이미지가 준비되기 전에 검사해 실패했다. 진화 이미지는 eager로 요청하고 QA는 이미지 decode 완료를 별도로 확인하도록 고쳐 전수 재검사 통과. 연출 진행이 다운로드에 묶이지 않는다.
- 배포 빌드에서 일반 진화 확정 직후 새로고침 → 이어하기: 그레이몬, HP 80/80, 진화 에너지 45, 완료 화면으로 복원. 비용은 50→45 한 번만 차감.
- 새 음악을 포함한 PWA 캐시 28개 OGG/MP3가 실제 AudioContext 디코딩에 성공했다. 서버 프로세스를 중단하고 페이지를 새로고침한 뒤 저장된 지도→메탈그레이몬 진화 완료, 전후 WebP 표시, 지도 음악 복귀를 확인했다. HP 100, 에너지 31로 정상 진행.

## PWA 업데이트

기존 v0.12 서비스워커가 있는 별도 테스트 origin에서 새 버전을 준비했다. 진행 중인 전투에서는 적용 버튼 비활성, 전투 종료 후 보상 화면에서는 활성임을 확인했다. 적용 후 제품 버전 0.13.0으로 바뀌었고 HP 56/64, 진화 에너지 6, 유대 2, 부담 2와 보상 3장(용기의 일격/비상 식량/몸으로 막기)이 동일했다. 진화 중 적용 차단 조건도 기존 `updateSafe`의 evolution 검사로 유지한다.

## 제한

Galaxy S23+ 모의 크기 384×832는 QA 입력값이며 실물 기기의 CSS viewport를 측정한 값이 아니다. 물리 Android/iOS, 설치 앱의 OS 백그라운드 강제 종료, 실제 스피커 청감/출력 지연은 미검증이다. 음악은 파일/디코딩/버스/타이밍으로 검증했으며 원작 곡을 복제하지 않았다. 저장은 기존 브라우저 localStorage이며 계정 동기화는 이번 범위가 아니다.
