## Codex 앱 내 브라우저

사용자 요청에 따라 Codex 내장 브라우저에서 로컬 프로덕션 미리보기를 직접 조작했다. 사용자 기존 저장과 분리된 포트 3018/3019를 사용했다.

- 빈 필수값은 미리보기 차단. 한글·줄바꿈·특수문자·이모지 입력, 미리보기와 체크 전 내보내기 비활성화 확인.
- 환경 그룹만 선택하면 그 정보만 포함. 합성 query/hash를 붙인 URL에서 pathname만 보고서에 포함됨을 확인.
- 실제 Markdown 복사와 `.md`/`.json` 다운로드 확인. 성공 aria-live, 복사 후 버튼 포커스 유지, 입력 변경 후 이전 미리보기·동의 무효화 확인.
- 신고 창을 닫고 다시 열면 초안 복원. 3,000자 한글 재현 단계에서 본문을 자르지 않고 빈 GitHub 양식 링크와 복사/다운로드 안내 제공.
- 1280×720, 390×844, 320×740에서 확인. 모바일 페이지/대화상자 가로 넘침 없음. 16px 입력 글자·최소 44px 조작 영역·레이블·포커스 표시 확인.
- 신태일 선택 → 챕터 → 도입 → 지도 → 첫 전투로 자연 진입. 신고 전후 전투 화면 텍스트 일치. 아구몬 HP 64/64, 쿠가몬 34/34, 턴 1, 에너지 3, 동일한 손패 5장 유지. 새로고침 후 이어하기에서도 해당 상태 유지.
- 전투 소리 활성화 후 신고 진단에서 context running/ogg/muted false 확인. 닫은 뒤 설정의 음악 재생 상태 유지. 물리 스피커 청감 검사는 아님.
- 최종 로컬 검증 탭의 콘솔 오류 없음. 스크린샷 `test-results/v0.11-report-mobile.jpg`는 로컬 검증 산출물이며 배포하지 않음.

## 범위와 한계

클립보드 거절은 자동 테스트에서 실패를 주입해 수동 선택 경로를 확인했다. 실제 브라우저의 클립보드 권한 거절이나 팝업 차단을 강제하지 않았으며, 정상 복사와 항상 제공되는 현재 탭 링크를 검증했다. 실제 iOS/Android 키보드와 스크린리더 낭독은 미검증이다. 공개 테스트 이슈를 생성하거나 제출하지 않는다. GitHub 작성 화면 및 배포 확인은 아래 기록으로 구분한다.
