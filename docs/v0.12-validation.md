# v0.12 · 공격 기술 연출 · 2026-11-06

## 구현과 출처

공격 카드 39종, 적의 공격/흡수 39개 패턴 슬롯을 전수 연결했다. [ID별 매핑](combat-effect-map.md)은 실제 카드·적·이펙트 데이터에서 생성한다. 게임 판정은 먼저 한 번 저장하고, 이전/이후 스냅샷의 실제 HP·방어 차이만 연출한다. 시각 발사체가 여러 개여도 피해 판정을 곱하지 않는다. 적 행동에 표시하는 연타 수 역시 기존 총 피해 규칙을 유지한다.

첫 구현의 공통 원형 시전 표시가 단조롭다는 사용자 피드백을 반영했다. 입 앞 점화, 머리 주변 방전, 뿌리/잎, 물 소용돌이, 앞발 궤적, 광궁, 발사구, 결정 파편, 축복, 어둠 연무 등 13종의 출발 실루엣을 사용한다. 시전자 반동·돌진·상승·뿌리 내리기 동작, 곡선 궤적, 색 그라데이션, 별도의 폭발·물보라·조임·빛 적중을 결합했다. 공격 중 살아 있는 상대의 투명도는 바꾸지 않는다.

`src/effect-data.ts`는 연결 데이터, `combat-effects.ts`는 판정 요약과 직접 작성한 SVG 모티프/위치 계산, `combat-effects.css`는 반응이다. 캐릭터의 현재 DOM 사각형과 기술별 출발 위치를 매 프레임 측정하여 스크롤·크기 변화에도 같은 장면 좌표를 사용한다. 선택 링과 UI는 유지한다. 추가 래스터·영상·음원·외부 의존성은 없고 기존 자체 제작 효과음을 사용한다. 공식 추출 에셋은 사용하지 않았다.

움직임 줄이기에서는 발사·이동·몸 반응 없이 120ms 정적 적중/방어/무효를 표시한다. 직접 피해가 0이면 거짓 피격을 만들지 않는다. 단일 대상, 살아 있는 광역 대상, 쓰러진 대상 제외, 흡수·반격·상태 피해를 구분한다. 백그라운드·페이지 종료·도움말 등으로 취소하면 큐, SVG, RAF, 카드 잔상과 combat 오디오를 함께 정리한다.

## 자동 검증

- `npm test`: 175개 통과. 카드/적 전수 매핑·기본 fallback·방어/부분 방어/사망/정화 제거·광역·연타 총 피해·무피해·정적 모션 및 기존 저장/오디오/입력 회귀.
- `node scripts/verify-combat-baseline.mjs`: 기존 엔진과 608개 시나리오, 8명, 카드·턴·난수·진화 판정 동일. 엔진 파일과 저장 schema를 변경하지 않았다.
- `npm run build`: TypeScript, Vite, PWA 성공. JS gzip 75.30kB, CSS gzip 16.79kB. 기존 v0.11 대비 gzip 약 8kB 증가. 별도 에셋 다운로드 증가 없음.

## 브라우저 검증 방식

Codex 앱 내 브라우저에서 별도 로컬 QA 포트의 실제 화면/입력/연출을 사용했다. `scripts/create-visual-qa.mjs`, `qa/effects-fixture.ts`가 생성하는 합성 전투이며 모든 기술을 자연 탐험으로 획득했다고 주장하지 않는다. QA 파일은 `dist`에 포함하지 않는다.

실제 입력으로 39카드(8명·기본/진화 기술), 39적 공격(작은 적·보스), 2명 적 광역, 취소·재진입·완전 방어를 재생하고 각 시전/적중 단계, 상태 일치, 잔상 제거를 검사한다. 정지 프레임은 실제 SVG 렌더러와 같은 코드로 만든 시각 검수용 장면이다. 관찰 및 배포 결과는 아래에 추가한다.

## 한계

320×740, 390×844 및 S23+ 모의 크기 384×832를 사용한다. S23+ 크기는 QA 입력값이며 실제 기기의 브라우저/디스플레이 설정을 측정한 결과가 아니다. 물리 Android/iOS의 터치 지연·오디오 청감·GPU 성능을 확인하지 않았다. 로컬 프레임 간격은 현재 데스크톱 브라우저 관찰값이며 모바일 FPS를 보장하지 않는다.
