# v0.15.1 검증 기록

2026-11-06. 기준: v0.15.0 `7c34eea`. 남은 프롬프트는 v0.15.1 한 건이며 다음 기능 버전은 추가하지 않았다.

## 구현

- 48개 전투 몸체에 대기·준비·발사·근접·피격·회복 6포즈를 적용했다. 파트너 그림 24종(공명 가트몬은 같은 몸체 공유), 적 24종이다. 47개는 프로젝트 그림을 참조한 신규 알파 WebP, 피코데블몬은 기존 프로젝트 SVG의 날개·팔·발 경로를 움직인 SVG 시트다. 기존 래스터를 관절별로 자르지 않았다.
- 몸체 전체 이동·확대 대신 고개·입·팔·날개·덩굴 등의 자세가 바뀐다. 몸체/기술별 발사 좌표, 적 방향과 포즈별 원본 방향을 보정했다. 가브몬의 이미지에 구워진 불꽃과 안드로몬의 잘못된 공격 방향은 재생성했다.
- 준비 → 궤적 → 접촉 → 회복을 연결했다. 엔진이 한 번 계산·저장한 결과를 연출용 스냅샷으로 보여주며 접촉 시 HP·방어·효과음이 갱신된다. 다단 공격은 기존 합산 피해를 타격 수로 나눠 표시한다. 피해를 다시 계산하거나 배수로 늘리지 않는다.
- 살아 있는 상대의 불투명도를 유지했다. 별도 카드 뒷면, 한 번 눌러 사용, 이름·HP 배치, 전투 진입 스크롤과 건너뛰기를 유지했다.
- 진화는 원본 비율을 유지하며 이전 실루엣·신호 잔광, 일반의 세로 등장/강제의 가로 균열/공명의 금빛을 구분했다. 기존 5.6초 음악 타임라인은 유지한다.
- 새 포즈는 해당 전투에서만 내려받고 런타임 캐시에 저장한다. 미방문 이미지가 오프라인에서 없을 때 쓸 기존 SVG 13개를 필수 캐시에 추가했다.

전투 엔진·밸런스·난수·진화 조건·계정 동기화는 변경하지 않았다. 저장 schema 3을 유지하고 제품/내보내기 앱 버전만 0.15.1로 변경했다.

## 제작과 매핑

[몸체·기술 매핑](combat-pose-map.md)에 48몸체, 39카드, 39적 공격의 포즈와 발사 위치를 기록했다. [출처](../assets/ATTRIBUTION.md) 및 `assets/animation-sources/*.json`에 실제 생성 프롬프트·프로젝트 참조 파일·날짜·보정을 남겼다. 공식 추출 이미지·음원은 사용하지 않았다.

`scripts/pack-battle-poses.py`는 전체 포즈 셀을 공통 축척/발 기준선으로 정렬해 320px 셀의 3×2 WebP로 압축한다. 신체 부위를 분리하지 않는다. 이어 `scripts/pack-vector-pose.mjs`로 SVG 항목을 추가한다. 원본 PNG와 화면 증거는 Git에서 제외한 `test-results/`에 보관하고 최적화 결과만 배포한다.

## 앱 내 브라우저

Windows Codex 앱 내 Chromium을 사용했다. 외부 Playwright/네이티브 앱 조작은 사용하지 않았다. 로컬 QA가 실제 게임 핸들러를 호출하며 QA는 프로덕션에 포함하지 않는다.

- 일반/감소 모션 각각 39카드·39적 공격·48몸체 통과. 카드/턴 중복 입력, 25/180/420ms 취소, 완전 방어, 다단 합산 피해와 최종 상태 일치. 일반 4접촉은 감소 모드에서 적별 1회씩 2접촉으로 요약된다.
- 17진화 경로를 두 모드에서 재생해 형태·비용·저장·음악 정리를 확인했다. 0/900/1800/3400ms 건너뛰기, 강제 진화 중 타이틀 이동, 지도 음악 복귀 통과. Enter로 건너뛰면 완료 화면과 ‘함께 앞으로’ 포커스로 이동했다.
- 8명 모두 진화 단계와 보스 승리/패배 확인. 별도 뒷면→앞면 360ms 뒤집기, 앞뒷면 동시 노출 방지, 보상 선택/건너뛰기, HUD 8종, 소리 토글 10회 통과.
- 음소거 후 공격 재생 결과 `muted:true, level:0, busy:false, remainingEffects:0`. Enter 카드 사용 확인.
- 의도적으로 포즈 URL을 누락시키자 기존 아구몬 WebP가 표시됐다. 정상 HTTP 검사에서 누락 자원은 없었다.
- 320×740, 390×844, Galaxy S23+를 가정한 CSS 384×832, 1280×900 검사. 가로 넘침 없음, 주요 몸체가 전장 안에 위치, 상단 버튼 최소 44px, 생존 디지몬 opacity 1. 320px 보상/HUD 검사를 별도 통과했다. 실기기가 아닌 viewport 에뮬레이션이다.
- Vercel 로컬 루트 및 `/index.html` 직접 접근·새로고침 시 v0.15.1, 깨진 이미지 없음.

일반 재생 96.6초의 rAF 간격 p95 16.8ms/최대 17.5ms, 50ms 초과 0/5,793표본. 감소 모션 21.3초는 p95 16.8ms/최대 17.4ms, 50ms 초과 0/1,278표본. 데스크톱 IAB 콜백 간격이며 GPU 프레임 시간·실기기 FPS·실제 터치 지연을 대신하지 않는다.

## 실제 오프라인·업데이트

별도 로컬 서버를 중단하고 새로고침→이어하기로 전투를 복원했다. 방문한 아구몬·쿠가몬 포즈가 캐시에서 표시됐다. 카드·문장·턴 진행으로 승리한 후 보상을 넘기고 일반 진화를 완료했다. 미방문 그레이몬 이미지는 선캐시 SVG로 대체됐다. 다시 새로고침해도 그레이몬/HP77/80·에너지51·유대16·부담2가 유지돼 비용이 중복 차감되지 않았다.

v0.15.0→v0.15.1 업데이트에서 전투 중 적용 비활성, 보상에서 적용 활성과 상태 보존을 확인했다. **첫 적용은 제한시간을 넘겼고 재시도 시 준비 실패 안내가 나왔다.** 탭을 닫고 다시 열자 새 버전으로 전환됐으며 보상/상태는 유지됐다. 로컬 SW 진단에서 설치·활성·claim 완료를 관찰했다. 진단 코드를 제거한 원본 프로덕션 worker로 다시 적용했을 때는 자동 새로고침/저장 보존을 통과했다. 최초 IAB 지연 원인은 미확정이며 추측으로 worker를 수정하지 않았다. 최초 실패를 성공으로 집계하지 않는다.

`v0.15.1-pwa-update.json`, `v0.15.1-offline-battle.jpg`, `v0.15.1-offline-evolution.jpg`에 기록했다. 사용자 운영 저장이나 클라우드 계정은 변경하지 않았다.

## 용량과 제한

- 새 포즈 48파일 **6,706,798B (6.40MiB)**, 가장 큰 3개 합계 710,258B. 제목에서는 요청하지 않는다.
- 제목 그림 약 0.34MB, 폰트 2.22MB, 압축 JS/CSS 0.11MB로 화면 구동 자원 약 **2.7MB**. 선택적 음악/PWA 설치는 별도다.
- 음악 선캐시를 포함한 PWA 설치는 **107파일 약 16.6MB 원본**. 전체 배포 약 30.1MB 원본/29.4MB 압축 추정이다. 전체 오프라인 설치가 10MB 이하라는 뜻은 아니다.
- 6키 포즈 방식이며 중간 동작을 모두 그린 24fps 애니메이션은 아니다. 프레임 간 작은 장식/선 차이가 남고 피코데블몬 SVG는 래스터보다 단순하다. 어두운 보스는 작은 2적 배치에서 명도 대비를 더 다듬을 여지가 있다.
- 실제 Android/iOS·저사양 기기·OS 백그라운드 강제 종료·설치형 앱 업데이트·물리 스피커/터치 지연·스크린리더 음성은 미검증이다. 앱 감소 모션/키보드는 검사했지만 OS 접근성 설정을 직접 변경해 시험하지는 않았다.
- 클라우드 운영 검증은 v0.15 기록을 따른다. 인증/동기화 로직은 변경하지 않았다.

## 재현

`npm ci`, `npm run dev` 후 `/file-island-echoes/`에 접속한다. 로컬 QA는 `node scripts/create-visual-qa.mjs`로 생성 후 `/file-island-echoes/test-results/visual.html`에서 실행한다. ‘v0.15.1 동작 검사’와 ‘v0.13 전체 검사’는 로컬 QA 데이터만 사용한다. 원본/증거 파일은 배포·Git에서 제외한다.
