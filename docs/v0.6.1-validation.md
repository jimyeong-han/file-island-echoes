# v0.6.1 구현·검증 기록

2026-09-11. 구현 시작 기준 `2fa6cbb` (제품 v0.6.0). 게임 규칙·진화 조건·저장 schema v2는 유지했다.

- 8개 문장 전용 SVG와 독자적인 원형 장치 심볼을 선택·상세·챕터·스토리·전투·도감·도움말에 연결했다. 생성 원본 경로 대신 프로젝트 에셋만 참조한다.
- 초상화 3종과 엔젤우몬을 재생성했다. 추가 사용자 지시대로 노트북 파인애플은 정중앙, 리키 모자에는 귀덮개가 없다. 나리의 숏컷과 가트몬의 몸 축/접지를 수정했다. 엔젤우몬의 8장 날개·전면 마스크·비대칭 의상·리본·홀리 링을 원본 및 전투 크기에서 확인했다.
- 내장 imagegen의 투명 요청 결과가 RGB 체커 패턴이어서 재생성한 단색 녹색 배경을 알파 WebP로 최적화했다. 알파 0~255, 총 50개 WebP 전투 스프라이트 감사 통과. 원본 PNG는 배포하지 않는다.
- 지속/문장/조건은 공통 dl/dt/dd로 표시한다. 도움말 3개 책갈피는 데이터와 KEYWORDS 사전을 재사용하고 키보드·선택 유지·Escape·모달 스크롤을 지원한다. 상단 도움말과 모든 화면의 정보 하단을 추가했다.
- 에너지의 기존 `writing-mode:vertical-rl`을 제거했다. 줄어들지 않는 자원 영역과 줄바꿈 가능한 HUD, 안정적인 툴바 열로 수정했다. 320px에서 음소거를 10번 전환한 도감 좌표/크기가 모두 동일했다. 수정 후 모바일 툴바는 두 열을 쓴다.

검증 환경: Chromium, 로컬 dev 3005의 UI fixture와 프로덕션 preview 3006. 실제 사용자 저장을 테스트에 사용하지 않았다.

1. 1280×900 주요 19개 화면 및 모달, 390×844 선택·상세·챕터·이벤트·보상·일반/강제 진화·결과, 320×740 도움말·설정·정보 확인. 가로 문서 넘침 및 누락 이미지 없음.
2. 384×854와 854×384 에너지 라벨 가로쓰기 확인. 320×740 / 글자 200% / 에너지 12에서도 라벨 한 줄, 주변 정보는 다음 행으로 이동하고 문서 넘침 없음. 실제 Galaxy S23+는 연결되어 있지 않아 CSS viewport로 검증했다.
3. 도움말 방향키/End와 Escape 후 책갈피 유지, aria-selected 및 tabpanel 연결 확인. 도감·정보 접근 가능. 나리의 선택/상세/도감 크롭과 엔젤우몬 전투 실루엣 확인.
4. 실제 새 탐험 → 태일 선택 → 챕터 → 인트로 → 전투, 공격/방어/턴 종료 → 새로고침 후 2턴 복원 → 전투 승리·카드 보상 → 이벤트 확인. 일반/강제 진화 및 보스/결과는 실제 엔진으로 만든 로컬 fixture에서도 확인했다.
5. `npm test`: 53개 통과. `npm run build`, `npm run check:pages`, `python scripts/audit-assets.py` 통과. HTTP 배포 경로 검사는 릴리스 시 함께 수행한다.

실기기 터치 오디오 청취와 Safari는 이번 환경에서 확인하지 못했다. 자동 오디오 회귀 테스트 및 Chromium 설정 조작은 통과했다. 기존 츄몬·데미데블몬 SVG는 이 버전 범위 밖이며 유지했다.
