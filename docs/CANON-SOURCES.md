# 등장 범위와 이름 확인

## v0.6.1 시각 특징 대조 · 2026-09-11

[토에이 공식 문장 상품의 여덟 심볼](https://store.toei-anim.co.jp/shop/g/gDGM00461P1/)을 브라우저에서 육안 확인했다. 용기=중심 원과 태양 광선, 우정=서로 도는 곡선과 양옆 물결, 사랑=말린 하트, 지식=서로 연결된 크기가 다른 원, 순수=내부 원이 있는 물방울, 성실=중앙 기둥과 교차 띠, 희망=상단 별과 아래 빛줄기, 빛=여덟 방향의 광채로 구분한다. 의미·명칭은 [1999년 작품의 문장 소개](https://www.toei-anim.co.jp/tv/dejimon/ranking/result13.html)와 대조했다. 상품 이미지나 벡터를 다운로드·추출하지 않고 `src/crests.ts`에서 24px 격자와 1.8px 선으로 새로 구성했다.

인물 의상과 엔젤우몬의 세부 기준은 사용자가 작성한 v0.6.1 프롬프트의 체크리스트를 따랐다. 한솔: 민트색 두꺼운 노트북, 노란 모서리·래치·덮개 정중앙의 직접 그린 파인애플, 주황 긴소매와 노란 장갑. 리키: 귀덮개 없는 녹색 모자, 대각선 밝은 띠와 파란 장식, 연녹색 긴소매. 초상화 거리 유지로 하의·신발은 프레임 밖이다. 나리: 귀·목이 드러나는 숏컷, 연노란 상의·분홍 스카프·바지, 가트몬의 머리부터 접지한 발까지 자연스러운 자세. 엔젤우몬: 비대칭 팔·다리, 오른 허벅지 두 버클 띠, 금색 양 날개 가슴 장식, 전면 마스크, 8장 날개, 긴 리본과 왼 발목 링. 기존 프로젝트 생성 그림을 편집했고 공식 일러스트의 포즈·선화를 복제하지 않았다.

게임 표시는 사용자의 최신 명명 요청대로 「디지몬: 우리들의 모험」을 유지한다. 둥근 장치·화면의 산과 신호선을 조합한 게임 심볼은 별도로 직접 그렸으며 공식 로고가 아니다.
