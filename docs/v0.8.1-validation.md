# v0.8.1 구현·검증 기록

기준: v0.8 `ac9a3ce`, 패치 요청 문서 `78b7f06`. 제품 버전 0.8.1. v0.9는 작업하지 않았다.

## 변경

- 공통 dialog를 제목/44×44 닫기 버튼의 헤더와 별도 스크롤 본문으로 분리했다. 기존 음수 margin, 전체 폭 sticky 배경과 겹침을 없앴다. 긴 제목은 왼쪽 열에서 줄바꿈하고 닫기는 오른쪽 정사각형에 남는다. 제목은 aria-labelledby로 연결한다.
- DOM 재생성 전 팝업을 연 action을 기억해 닫기 및 Escape에서 포커스를 복원한다. 중첩 저장 메뉴에서도 최초 진입 버튼으로 복귀한다. 같은 팝업에서 설정을 바꿔도 본문 스크롤 위치를 유지한다.
- 에너지 위 compact 체력과 combat-anchor를 제거했다. 행동 알림은 스크린리더용 live status로 유지하며 빈 행은 남기지 않는다. 파트너 아래 체력 meter와 기존 상단 상태는 유지했다.
- 전투 헤더의 시각/DOM 순서는 지역·제목 → 능력·적 분석 → 턴이다. 분석 버튼은 한 번만 표시하고 기존 기능을 연다. 전투 안내는 상단 공통 도움말에서 접근한다.
- 선택 대상 텍스트 행과 기존 하단 선을 제거했다. 선택된 살아 있는 적의 기존 fighter-base에 고정 이중 타원 링을 그린다. 새 세로 공간이나 적별 좌표를 추가하지 않는다. 버튼은 aria-pressed와 이름/선택 상태를 노출하고 키보드 포커스는 별도 점선이다. 죽은 적에는 링이 없다.
- 작업 중 최종 사용자 지시에 따라 파트너·적 모두 방어도/받는 효과 → 이미지 → 이름 → 체력 순서로 통일했다. 적에게는 다음 행동 예고와 선택 링만 추가된다. 체력 숫자/막대의 서식과 기본 색상도 맞췄다.
- 엔진, 대상 판정, 밸런스, 카드 효과, 저장 schema v2는 변경하지 않았다. 새 에셋이나 의존성은 없다.

## 검증

- `npm test`: 96개 통과. 레이아웃 5개 추가: dialog 헤더/본문 분리, 제목·분석·턴 순서, 선택/전투 불능 접근성, 문자열 escape, 실제 UI 연결 및 단일 체력/이름 위치.
- `npm run build`, `npm run check:pages`: 통과. 로컬 프로덕션 HTTP 215 URL 모두 200, 최신 빌드 및 /file-island-echoes/ 기본 경로 확인.
- 기존 엔진 비교 608개 시나리오: 카드 비용/효과, 적 결과, 난수와 진화 결과 일치.
- 로컬 전용 `qa/layout-checks.ts`: 두 적 대상 6회 전환 시 상대 좌표/전장 크기 고정, 단일 aria-pressed, 선택한 적에 공격 적용, 단일 파트너 meter, 이름·효과 DOM 위치 확인.
- 도움말/설정/도감/덱/분석/귀환/데이터 관리/초기화 확인/진화/새 탐험 확인 팝업에서 닫기 44×44, 제목과 본문 비중첩, 제목 클릭 가로채기 없음, 본문 스크롤 중 닫기 위치 고정, 초기 포커스와 닫은 뒤 포커스 복귀 확인. 초기화나 새 탐험 확정 등 파괴적 동작은 실행하지 않았다.
- 390×844 및 320×740 문서 글자 200%에서 위 DOM 검사 전체 통과. 200%는 rem 기반 문서 확대이며 OS 확대나 브라우저 전체 줌과는 다르다.
- 동일 390px / 신태일 / 두 적 fixture에서 전장 상단→손패 상단: 642.09px → 528.09px, 114px 감소. 전장 자체 333.5px → 323.5px. 대상 변경은 문서 스크롤과 별개로 전장 내부 상대 좌표가 일정하다.

실기기 Galaxy S23+와 iOS Safari는 연결되어 있지 않아 실제 기기의 CSS viewport 및 터치/성능은 검증하지 못했다. 모바일 크기 검증은 데스크톱 Chromium에서 수행했다.


## 최종 확인

- 1280×900에서도 전체 레이아웃 DOM 검사 통과. 8명 첫 배분 → 한 번 터치 카드 → 3턴, 중복 입력 잠금, 두 적 순서, 체력, 승리/사망/메뉴 취소 회귀 검사 ALL PASS.
- 384×854 프로덕션 빌드의 기존 저장 이어하기(턴 2)와 전투 배치를 육안 확인했다. 분석 진입 후 Escape, Enter로 다시 열기, Space로 닫기에서 분석 버튼으로 포커스 복귀를 확인했다.
- 전투 불능 적은 disabled/aria-pressed=false/링 없음, 살아 있는 선택 적만 링 표시. 약화·화상을 양쪽에 부여한 fixture에서 이미지 위 표시를 확인했다. 표시 서식은 양쪽 모두 같은 span 행이다.
- 데블몬 보스 및 움직임 줄이기에서 타깃 링 border 2px, animation none, 턴 진행과 입력 잠금 해제 확인.
- 검증용 fixture와 검사 모듈은 배포 번들에 포함되지 않는다. 공개용 리소스/오디오는 기존 파일 그대로다.
